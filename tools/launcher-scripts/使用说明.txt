================================================================
  Veyra 2.2.0 个人定制版 / 作者完整版  —  使用说明
================================================================

这是 Veyra 视频播放器的两个版本，装在同一个文件夹里，
用不同的启动脚本切换，互不影响。


一、先看这里：两个版本怎么选
----------------------------------------------------------------

  启动-个人定制版.cmd     ← 推荐日常使用
      在作者 2.2.0 基础上加了：
        * B 站播放：把视频页网址粘进「网络视频」就能播
        * B 站弹幕（可在设置里开关、调字号/透明度/速度）
        * B 站 CC 字幕，支持 中文 / 英文 / 双语 三种
        * 字幕配色：5 套预设 + 自定义字体色和底色
        * 杜比视界高光增强（设置里可开关，看 DV 片源更亮更透）
        * 浏览器插件一键拉起播放

  启动-作者完整版.cmd     ← 纯作者原版，出问题时用来对照
      作者发布的 2.2.0 原样，没有任何定制改动。
      如果你的显卡驱动/设备在定制版上表现异常，
      先用这个版本试，能运行说明是定制部分的问题。


二、第一次使用
----------------------------------------------------------------

  1. 把这个文件夹整个放到任意位置（路径建议纯英文，例如 D:\Veyra）
  2. 双击「启动-个人定制版.cmd」
  3. 第一次启动会自动创建你的个人数据目录，不需要手动配置

  注意：不要直接双击 veyra_qml_ui.exe，那样会用默认数据目录，
        和启动脚本用的不是同一个。


三、B 站播放怎么用
----------------------------------------------------------------

  方式一：复制 B 站视频页网址（bilibili.com/video/BV...），
          然后播放器里「网络视频」粘贴打开。

  方式二：装 Chrome/Edge 插件（可选）
          1) 打开 chrome-extension 文件夹
          2) 浏览器进扩展管理页，开启「开发者模式」
          3) 点「加载已解压的扩展程序」，选 chrome-extension 文件夹
          4) 打开 B 站视频页，点插件按钮 →「用 Veyra 打开」
          5) 如果插件拉不起来，双击 install-protocol.cmd 注册协议

  支持的网址：
    https://www.bilibili.com/video/BVxxxxxxxx
    https://b23.tv/xxxxxxx           （短链）
    https://www.bilibili.com/video/av123456
    带 ?p=2 这种分P也能识别

  注意：作者完整版不支持 B 站播放（作者主动删了这个模块）。


四、弹幕和字幕设置在哪
----------------------------------------------------------------

  设置 → 播放，往下找到「B 站弹幕 / B 站字幕」那一组。

  可以调：
    - 弹幕开关、字号、不透明度、速度、显示区域
    - 字幕开关、语言（中文/英文/双语）
    - 字幕字体颜色、底色、底色透明度（5 套预设）

  说明：
    * 颜色改动是实时的
    * 弹幕/字幕开关、字幕语言改了要重新打开视频才生效


五、杜比视界高光增强
----------------------------------------------------------------

  设置 → 播放 → 杜比视界 里的「高光增强」开关。

  作用：杜比视界片源在保留作者创作意图的前提下，把高光部分按场景
        实际亮度展开，而不是硬压到固定值。看 HDR 电影时高光更自然。

  要求：显示器支持 HDR，且 Windows 里打开了 HDR。
        如果画面发灰/过曝，把这个开关关掉即可。


六、实时字幕翻译（可选功能）
----------------------------------------------------------------

  这是作者 2.2.0 自带的功能，不是定制内容。

  它抓取 Windows 系统的「实时字幕」再去翻译，不是翻译视频自带字幕。
  用法：
    1. 按 Win + Ctrl + L 打开 Windows 实时字幕
    2. 播放没有中文字幕的英文内容
    3. 翻译结果会叠加在画面顶部

  第一次用需要在「设置 → 字幕 → 实时翻译设置」里下载翻译模型
  （约 1.1 GB，只下一次）。这个包为了减小体积没有附带模型。


七、系统要求
----------------------------------------------------------------

  - Windows 10 1809 或更新 / Windows 11
  - 64 位系统
  - 建议 NVIDIA 显卡（包里带的是 NVIDIA 版运行时）
    用 AMD 显卡也能开，但部分功能不可用
  - 首次播放 4K 需要一定性能，老机器建议降低画质


八、常见问题
----------------------------------------------------------------

  Q: 双击启动脚本，黑窗口一闪就没了，程序没起来？
  A: 用「启动-作者完整版.cmd」试一下。如果作者版能起，说明是定制
     部分的问题，把日志发给我（logs 文件夹里的 veyra-qml.log）。

  Q: B 站视频播不了？
  A: 1) 确认用的是「个人定制版」
     2) 4K 需要 B 站大会员，普通账号最高 1080P
     3) 部分番剧/直播页面不支持（只支持普通视频页）

  Q: 只有画面没有声音？
  A: 快速切换片源时可能触发。等上一段完全停下来再开下一段即可。

  Q: 弹幕或字幕开关自己变回关了？
  A: 去设置里重新打开。程序退出时偶尔会重置这两项。

  Q: 切换版本后设置变了？
  A: 两个版本的数据目录是分开的：
       个人定制版 → runtime_local\user-data-2.0.0
       作者完整版 → runtime_local\user-data-2.0.0-author
     这是正常设计，互不干扰。

  Q: 想再发给别人？
  A: 双击「打包分享版.cmd」，会在上一级目录生成一个干净副本
     （自动排除你的个人数据、播放历史和日志）。


九、这个包里的文件说明
----------------------------------------------------------------

  veyra_qml_ui.exe            当前正在用的程序（切换脚本会替换它）
  veyra_qml_ui.exe.custom     个人定制版程序
  veyra_qml_ui.exe.orig       作者原版程序（不要删，切回来要靠它）

  qml\Veyra\                 当前界面文件
  qml.custom\Veyra\          个人定制版界面
  qml.orig\Veyra\            作者原版界面

  shaders\                   当前着色器
  shaders\*.dxil.custom      个人定制版着色器
  shaders\*.dxil.orig        作者原版着色器

  启动-个人定制版.cmd         切到定制版并启动
  启动-作者完整版.cmd         切到作者版并启动
  打包分享版.cmd              生成可分享的干净副本
  install-protocol.cmd        注册 veyra:// 协议（插件用）
  chrome-extension\           浏览器插件（可选安装）
  runtime\  runtime_local\    运行库（不要动）
  logs\                      运行日志（出问题时发给我）


十、出问题时怎么反馈
----------------------------------------------------------------

  把 logs\veyra-qml.log 发给我，最好说明：
    - 用的是哪个版本（个人定制版 / 作者完整版）
    - 播的什么片源（本地文件 / B 站网址）
    - 显卡型号
    - 具体现象（黑屏 / 花屏 / 没声音 / 卡住）
